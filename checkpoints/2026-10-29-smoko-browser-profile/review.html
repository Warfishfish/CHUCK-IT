Smoko browser performance profile

This optional panel is for gathering host and guest frame-pacing readings on their own browsers. It only runs in Smoko gameplay.

Reading the panel

  • Approximate FPS and average/p95 frame interval describe the local browser game loop.
  • 33 ms frames count visible long stalls in the five-second rolling window.
  • Fixed backlog counts render samples where the simulation had at least 16.7 ms waiting in its fixed-step accumulator.
  • HOST or GUEST labels identify the local peer. No readings are sent to the other player.

Try it after review

  1. Open the browser game with ?perf=1 added to the URL.
  2. Both host and guest must open the same opt-in URL, refresh, and start a fresh Smoko yard.
  3. After several seconds, record each device's FPS, p95, long-frame count and fixed-backlog count from the upper-right panel.
  4. Compare while standing still, walking/carrying, and during a busy fight. Keep the game tab visible.

Limits and status

Measurements are local browser loop timing, not GPU timestamps or network latency. A high p95 on one device points toward local frame pacing; similar frame timing with rubber-banding points toward movement/network sync. These readings help narrow the cause, but do not by themselves prove it.
